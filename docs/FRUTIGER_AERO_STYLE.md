# Стиль Frutiger Aero

## Что такое Frutiger Aero?

Frutiger Aero — это эстетический стиль, популярный в период с 2004 по 2013 год, характеризующийся использованием глянцевых поверхностей, ярких цветов, природных элементов и эффектов прозрачности. Название происходит от шрифта Frutiger и концепции "aero" (воздух) из Windows Aero.

## Ключевые элементы стиля в этом проекте

### 1. Градиенты
- Вертикальные градиенты от голубого неба к зеленой траве
- Плавные переходы между цветами
- Яркие, насыщенные тона

### 2. Glass Morphism (Стеклянный эффект)
- Полупрозрачные панели с размытием фона
- Белые границы с высокой непрозрачностью
- Мягкие тени для создания объема

### 3. Природные элементы
- Небо с облаками (анимированный фон)
- Зеленая трава в нижней части градиента
- Водные оттенки синего цвета

### 4. Глянец и блики
- Кнопки с градиентом и верхним бликом
- Эффект "стеклянной" поверхности
- Отражения и свечение

### 5. Анимации
- Движущиеся облака на фоне
- Плавные hover-эффекты
- Подъем карточек при наведении

### 6. Цветовая палитра
```css
--primary-blue: #0078d7      /* Основной синий */
--primary-green: #7cb342      /* Основной зеленый */
--sky-blue: #87ceeb           /* Небесно-голубой */
--aero-blue: #4fc3f7          /* Aero синий */
--aero-green: #81c784         /* Aero зеленый */
```

### 7. Типографика
- Чистые, современные шрифты без засечек
- Segoe UI (родной шрифт Windows Aero)
- Хорошая читаемость на светлом фоне

## Технические реализации

### CSS Backdrop Filter
```css
backdrop-filter: blur(10px);
-webkit-backdrop-filter: blur(10px);
```

### Многослойные тени
```css
box-shadow: 
    0 8px 32px rgba(0, 0, 0, 0.1),
    inset 0 1px 0 rgba(255, 255, 255, 0.8);
```

### Анимированный градиент
```css
background: linear-gradient(180deg, 
    #87ceeb 0%, 
    #4fc3f7 30%, 
    #98fb98 60%, 
    #7cb342 100%);
```

### Ключевые кадры для облаков
```css
@keyframes clouds {
    0%, 100% { transform: translateX(0) translateY(0); }
    25% { transform: translateX(20px) translateY(-10px); }
    50% { transform: translateX(0) translateY(-20px); }
    75% { transform: translateX(-20px) translateY(-10px); }
}
```

## Вдохновение

Стиль вдохновлен интерфейсами эпохи:
- Windows Vista / 7 (Aero тема)
- macOS Aqua (ранние версии)
- Windows XP (Luna тема)
- Продукты Microsoft того периода (Windows Media Player, Xbox)

## Адаптивность

Проект полностью адаптивен и использует:
- CSS Grid для сеток курсов
- Flexbox для навигации
- Медиа-запросы для мобильных устройств
- Относительные единицы измерения (rem, %)

## Совместимость

- Современный Chrome, Firefox, Safari, Edge
- Частичная поддержка backdrop-filter (может требовать префиксов)
- Graceful degradation для старых браузеров
