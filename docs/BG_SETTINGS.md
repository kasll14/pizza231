# Настройки фонового изображения и стеклянных панелей

## Расположение
Файл конфигурации: `config/config.php`

## Фоновое изображение

| Константа | По умолчанию | Описание | Диапазон |
|-----------|-------------|----------|----------|
| `BG_IMAGE_PATH` | `/assets/images/background.png` | Путь к изображению | Любой валидный путь |
| `BG_IMAGE_BLUR` | `8` | Размытие фона (px) | 0-20 |
| `BG_IMAGE_OVERLAY_COLOR` | `255, 255, 255` | Цвет оверлея (RGB) | 0-255 |
| `BG_IMAGE_OVERLAY_OPACITY` | `0.3` | Прозрачность оверлея | 0.0-1.0 |
| `BG_IMAGE_SCALE` | `1.1` | Масштаб (для компенсации размытия) | 1.0-1.5 |

## Стеклянные панели (Glassmorphism)

| Константа | По умолчанию | Описание | Диапазон |
|-----------|-------------|----------|----------|
| `GLASS_ENABLED` | `true` | Включить эффект | true/false |
| `GLASS_CONTOUR_WIDTH` | `8` | **Ширина стеклянного контура в px** | 0-20 |
| `GLASS_CONTOUR_BLUR` | `10` | Размытие под контуром (px) | 0-20 |
| `GLASS_BORDER_COLOR` | `255, 255, 255` | Цвет контура (RGB) | 0-255 |
| `GLASS_BORDEROpacity` | `0.6` | Прозрачность контура | 0.0-1.0 |
| `GLASS_INNER_BG` | `255, 255, 255` | Цвет внутреннего фона (RGB) | 0-255 |
| `GLASS_INNER_OPACITY` | `0.95` | Прозрачность внутреннего фона | 0.0-1.0 |
| `GLASS_SHADOW_COLOR` | `0, 0, 0` | Цвет тени (RGB) | 0-255 |
| `GLASS_SHADOW_OPACITY` | `0.12` | Прозрачность тени | 0.0-1.0 |
| `GLASS_RADIUS` | `20` | Радиус скругления (px) | 0-50 |

## Как это работает

### Стеклянный контур:
- **Внутренняя часть панели**: белый фон (`GLASS_INNER_BG` с `GLASS_INNER_OPACITY`)
- **Контур (рамка)**: полупрозрачный, с размытием фона под ним (`backdrop-filter`)
- **Ширина контура**: настраивается через `GLASS_CONTOUR_WIDTH` (по умолчанию 8px)

### Примеры настройки

**Тонкий контур (2px):**
```php
define('GLASS_CONTOUR_WIDTH', 2);
define('GLASS_CONTOUR_BLUR', 5);
```

**Толстый контур (12px):**
```php
define('GLASS_CONTOUR_WIDTH', 12);
define('GLASS_CONTOUR_BLUR', 15);
```

**Без контура (только белые панели):**
```php
define('GLASS_CONTOUR_WIDTH', 0);
define('GLASS_INNER_OPACITY', 1.0);
```

**Цветной контур:**
```php
define('GLASS_BORDER_COLOR', '135, 206, 235'); // Голубой
define('GLASS_BORDEROpacity', 0.8);
```

**Прозрачная внутренняя часть:**
```php
define('GLASS_INNER_OPACITY', 0.7);
define('GLASS_CONTOUR_WIDTH', 4);
```

## Примечание

После изменения настроек в `config/config.php`:
1. Обновите страницу браузера (Ctrl+F5)
2. Если изменения не применились, очистите кэш браузера
