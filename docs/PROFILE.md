# Личный кабинет пользователя

## Обзор

Добавлена страница профиля пользователя с историей заказов и возможностью управления аккаунтом.

## Маршруты

| URL | Метод | Описание |
|-----|-------|----------|
| `/profile` | GET | Главная страница профиля |
| `/profile/update` | POST | Обновление данных профиля (логин, email) |
| `/profile/change-password` | POST | Смена пароля |

## Функционал

### 1. Информация о профиле
- Просмотр и редактирование логина и email
- Дата регистрации
- Статус подтверждения email
- Смена пароля

### 2. Статистика
- Количество заказов
- Общая сумма покупок
- Количество выполненных заказов

### 3. История заказов
- Таблица со всеми заказами пользователя
- Номер заказа, дата, статус
- Список курсов в заказе
- Сумма заказа
- Детальный просмотр заказа в модальном окне

### 4. Статусы заказов
- **В обработке** (pending) - оранжевый
- **Оплачен** (paid) - синий
- **Выполнен** (completed) - зелёный
- **Отменён** (cancelled) - красный

## Доступ

Страница профиля доступна только авторизованным пользователям. При попытке доступа без авторизации происходит перенаправление на страницу входа.

## Интеграция

Ссылка на профиль добавлена в главное меню (видна только авторизованным пользователям).
