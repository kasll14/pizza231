# Инструкция по запуску проекта Frutiger Aero Courses

## Шаг 1: Установка XAMPP

Если у вас еще не установлен XAMPP:
1. Скачайте с официального сайта: https://www.apachefriends.org/
2. Установите в директорию `C:\xampp`
3. Запустите `xampp_start.exe`

## Шаг 2: Размещение проекта

1. Скопируйте весь проект в папку `C:\xampp\htdocs\`
2. Убедитесь, что путь к проекту: `C:\xampp\htdocs\online-courses`

## Шаг 3: Настройка базы данных

### Вариант A: Через phpMyAdmin
1. Откройте браузер и перейдите по адресу: `http://localhost/phpmyadmin`
2. Нажмите "Импорт"
3. Выберите файл `database.sql` из папки проекта
4. Нажмите "Вперед" для выполнения

### Вариант B: Через командную строку
1. Откройте командную строку (cmd) от имени администратора
2. Перейдите в папку проекта:
   ```
   cd C:\xampp\htdocs\online-courses
   ```
3. Запустите скрипт:
   ```
   C:\xampp\mysql\bin\mysql.exe -u root < database.sql
   ```

## Шаг 4: Настройка sendmail для отправки писем

1. Откройте файл `C:\xampp\sendmail\sendmail.ini`
2. Найдите и измените следующие параметры:
   ```
   smtp_server=smtp.gmail.com
   smtp_port=587
   auth_username=ВАШ_GMAIL
   auth_password=ВАШ_ПАРОЛЬ_ПРИЛОЖЕНИЯ
   from_email=noreply@frutiger-courses.ru
   ```

3. Откройте файл `C:\xampp\php\php.ini`
4. Найдите строку `;extension=openssl` и уберите точку с запятой в начале:
   ```
   extension=openssl
   ```

5. Перезапустите Apache в панели XAMPP

## Шаг 5: Активация администратора

1. Откройте phpMyAdmin: `http://localhost/phpmyadmin`
2. Выберите базу данных `frutiger_courses`
3. Перейдите в таблицу `users`
4. Найдите пользователя с email `admin@example.com`
5. Измените значение `is_admin` с `0` на `1`

Или выполните SQL-запрос:
```sql
UPDATE users SET is_admin = 1 WHERE email = 'admin@example.com';
```

## Шаг 6: Запуск проекта

1. Убедитесь, что Apache и MySQL запущены в XAMPP Control Panel
2. Откройте браузер и перейдите по адресу: `http://localhost/online-courses`

## Доступы

### Администратор
- Email: `admin@example.com`
- Код подтверждения придет на почту (если настроен sendmail)
- Или используйте любой email для тестирования

### Обычный пользователь
- Email: `user1@example.com` или любой другой

## Проверка функционала

### 1. Главная страница
- Откройте `http://localhost/online-courses`
- Проверьте анимированный фон в стиле Frutiger Aero

### 2. Авторизация
- Нажмите "Вход"
- Введите email
- Проверьте получение кода подтверждения (если настроен sendmail)
- Введите код для входа

### 3. Просмотр курсов
- Перейдите в раздел "Курсы"
- Проверьте отображение всех курсов

### 4. Корзина и заказ
- Добавьте курс в корзину
- Перейдите в корзину
- Оформите заказ
- Проверьте email с подтверждением

### 5. Админ-панель
- Войдите под администратором
- Перейдите в "Админ-панель"
- Проверьте все разделы:
  - Управление курсами (добавление, редактирование, удаление)
  - Управление пользователями
  - Управление заказами
  - Просмотр логов

### 6. Страница "О нас"
- Откройте страницу "О нас"
- Проверьте работу Яндекс.Карты
- Убедитесь, что карта указывает на Кемеровский Кооперативный Техникум

## Возможные проблемы и решения

### Проблема: База данных не создается
**Решение:** Убедитесь, что MySQL запущен в XAMPP Control Panel

### Проблема: Письма не отправляются
**Решение:** 
- Проверьте настройки sendmail.ini
- Убедитесь, что включен модуль openssl в php.ini
- Попробуйте использовать SMTP вашего провайдера

### Проблема: Стили не загружаются
**Решение:** 
- Проверьте путь к CSS файлу
- Очистите кэш браузера
- Убедитесь, что файл assets/css/style.css существует

### Проблема: Сессии не работают
**Решение:** 
- Убедитесь, что папка `logs` имеет права на запись
- Проверьте настройки сессий в php.ini

### Проблема: Карта не отображается
**Решение:** 
- Для полноценной работы нужен API ключ Яндекс.Карт
- Для тестирования карта будет отображаться без ключа с предупреждением

2. Логи MySQL в панели XAMPP
3. Логи приложения в папке `logs/access.log`
