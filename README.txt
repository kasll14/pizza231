БЫСТРЫЙ СТАРТ:
--------------
1. Убедитесь, что XAMPP запущен (Apache + MySQL)

2. Создайте базу данных:
   - Откройте http://localhost/phpmyadmin
   - Импортируйте файл database/database.sql

3. Активируйте администратора:
   - В phpMyAdmin выполните:
   UPDATE users SET is_admin = 1 WHERE email = 'admin@example.com';

4. Откройте сайт:
   http://localhost/online-courses/

=================================================
Подробная документация в папке docs/
=================================================

Структура проекта:
- public/        - Точка входа (index.php)
- config/        - Конфигурация
- controllers/   - Контроллеры MVC
- models/        - Модели данных
- views/         - Представления
- assets/        - CSS стили
- database/      - SQL скрипты
- scripts/       - Скрипты установки
- logs/          - Логи системы
- docs/          - Документация
