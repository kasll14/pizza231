# Assets - Ресурсы проекта

## CSS

### style.css
Основные стили проекта в стиле Frutiger Aero.

#### Особенности стиля:
- Градиенты: небо (голубой), трава (зеленый), вода (синий)
- Glass morphism (эффект матового стекла)
- Анимированный фон с движущимися облаками
- Глянцевые кнопки с бликами
- Плавные переходы и тени
- Адаптивный дизайн

#### Цветовая палитра:
- Primary Blue: #0078d7
- Primary Green: #7cb342
- Sky Blue: #87ceeb
- Aero Blue: #4fc3f7
- Aero Green: #81c784

## Изображения

Для курсов можно добавить изображения в папку `assets/images/` (создайте при необходимости).

По умолчанию используются градиентные заглушки с первыми двумя буквами названия курса.

## Шрифты

Проект использует системные шрифты для быстрой загрузки:
- Segoe UI (Windows)
- Tahoma, Geneva, Verdana

## Анимации

### Анимированный фон
- Плавное движение облаков
- Градиентный переход от неба к траве
- Эффект глубины и объема

### Интерактивные элементы
- Hover эффекты на кнопках
- Подъем карточек курсов
- Плавные переходы между состояниями
